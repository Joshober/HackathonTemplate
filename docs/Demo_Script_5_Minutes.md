# Demo Script (5 Minutes)

## 0:00 - 0:30 Intro

- Open `/`
- One-line value: "Everything a business traveler needs before, during, and after the trip."
- Explain 4-stage journey in app.

## 0:30 - 1:45 Plan

- Open `/home`, stage `Plan`
- Select trip and run **Generate checklist**
- Show:
  - checklist tasks
  - risk flags
  - tradeoff guidance
- State: "Copilot prepares before-booking confidence, not just generic advice."

## 1:45 - 2:45 Approve

- Move to `Approve`
- Run **Prepare approval guidance**
- Show:
  - plain-language status
  - required approvers
  - fast fixes
  - timeline
- State: "Approval feels guided, not bureaucratic."

## 2:45 - 4:00 Travel / Issues

- Move to `Travel`
- In **Issue & Escalation Assistant**, choose `Cancellation`
- Enter disruption details and run triage
- Show:
  - concise situation summary
  - ranked next options
  - escalation level + action now
- Click **Escalate now** to open case
- State: "Copilot knows when to stop chatting and hand off."

## 4:00 - 4:45 Return

- Move to `Return`
- Run **Generate follow-up tasks**
- Mark one task `done`
- State: "Trip closure is explicit: expenses, feedback, compliance."

## 4:45 - 5:00 Privacy

- Open Assistant (`/assistant`) and send one prompt
- Point out privacy/context indicators (`privacyApplied`, context chips)
- Close: "Boundaries are clear; only minimized fields are sent to AI."
